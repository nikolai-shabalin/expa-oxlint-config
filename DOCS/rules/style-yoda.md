# style/yoda

Правило `yoda` из набора `style` контролирует аспект «Yoda». Оно помогает избегать проблем в коде, связанных с требованием «yoda», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/yoda.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило style/yoda выполняется.

```js
function examplePassingStyle() {
  // Требование «yoda» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило style/yoda сигнализирует о проблеме.

```js
function exampleFailingStyle() {
  // Требование «yoda» нарушено.
  return false;
}
```
