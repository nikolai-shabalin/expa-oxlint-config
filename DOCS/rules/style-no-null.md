# style/no-null

Правило `no-null` из набора `style` контролирует аспект «No Null». Оно помогает избегать проблем в коде, связанных с требованием «no null», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/no-null.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило style/no-null выполняется.

```js
function examplePassingStyle() {
  // Требование «no null» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило style/no-null сигнализирует о проблеме.

```js
function exampleFailingStyle() {
  // Требование «no null» нарушено.
  return false;
}
```
