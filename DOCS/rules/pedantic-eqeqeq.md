# pedantic/eqeqeq

Требует использования строгого равенства (=== и !==) вместо нестрогого (== и !=).

## Описание

Операторы == и != выполняют приведение типов перед сравнением, что может привести к неожиданным результатам. Строгие операторы === и !== не выполняют приведение типов и сравнивают как значение, так и тип.

## Проблемные примеры

```javascript
// Нестрогое сравнение может дать неожиданные результаты
if (x == y) {
    // код
}

if (a != b) {
    // код  
}

// Примеры неожиданного поведения:
"" == 0;        // true
0 == false;     // true
null == undefined; // true
[1] == 1;       // true
```

## Правильные примеры

```javascript
// Строгое сравнение более предсказуемо
if (x === y) {
    // код
}

if (a !== b) {
    // код
}

// Явное приведение типов при необходимости
if (Number(x) === Number(y)) {
    // код
}

if (Boolean(condition) === true) {
    // код
}
```

## Исключения

Правило позволяет использовать == и != для сравнения с null, так как это распространённая практика для проверки на null и undefined одновременно:

```javascript
// Разрешено
if (value == null) {
    // проверяет как null, так и undefined
}

if (value != null) {
    // проверяет что значение не null и не undefined
}
```

## Конфигурация

```json
{
    "rules": {
        "eqeqeq": ["error", "always"]
    }
}
```

Опции:
- `"always"` - всегда требует строгое равенство
- `"smart"` - разрешает некоторые случаи нестрогого сравнения
