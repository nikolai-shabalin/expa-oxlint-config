# eqeqeq

Требует использования операторов строгого равенства (`===` и `!==`) вместо операторов нестрогого равенства (`==` и `!=`). Строгое сравнение предотвращает неожиданные приведения типов.

## Проблемные примеры

```javascript
if (x == y) {
  // может привести к неожиданным результатам
}

if (obj.prop != null) {
  // неявное приведение типов
}

switch (value) {
  case 1:
    // == используется в switch по умолчанию
}
```

## Корректные примеры

```javascript
if (x === y) {
  // строгое сравнение
}

if (obj.prop !== null && obj.prop !== undefined) {
  // явная проверка
}

// или
if (obj.prop != null) { // исключение для проверки null/undefined
  
}

if (typeof value === 'number') {
  // строгое сравнение с typeof
}
```
