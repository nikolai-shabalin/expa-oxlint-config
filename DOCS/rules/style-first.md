# style/first

Правило `first` из набора `style` контролирует аспект «First». Оно помогает избегать проблем в коде, связанных с требованием «first», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/first.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило style/first выполняется.

```js
function examplePassingStyle() {
  // Требование «first» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило style/first сигнализирует о проблеме.

```js
function exampleFailingStyle() {
  // Требование «first» нарушено.
  return false;
}
```
