# style/curly

Правило `curly` из набора `style` контролирует аспект «Curly». Оно помогает избегать проблем в коде, связанных с требованием «curly», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/curly.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило style/curly выполняется.

```js
function examplePassingStyle() {
  // Требование «curly» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило style/curly сигнализирует о проблеме.

```js
function exampleFailingStyle() {
  // Требование «curly» нарушено.
  return false;
}
```
