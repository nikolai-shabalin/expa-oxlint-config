# style/new-cap

Правило `new-cap` из набора `style` контролирует аспект «New Cap». Оно помогает избегать проблем в коде, связанных с требованием «new cap», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/new-cap.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило style/new-cap выполняется.

```js
function examplePassingStyle() {
  // Требование «new cap» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило style/new-cap сигнализирует о проблеме.

```js
function exampleFailingStyle() {
  // Требование «new cap» нарушено.
  return false;
}
```
