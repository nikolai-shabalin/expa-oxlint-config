# correctness/for-direction

Обеспечивает правильное направление цикла for. Правило проверяет, что счётчик цикла for изменяется в правильном направлении.

## Описание

Это правило проверяет циклы for, чтобы убедиться, что условие завершения цикла в конечном итоге будет достигнуто. Цикл for с неправильным направлением будет выполняться бесконечно.

## Проблемные примеры

```javascript
// Бесконечный цикл - i увеличивается, но условие i >= 0
for (var i = 0; i >= 0; i++) {
    // код
}

// Бесконечный цикл - i уменьшается, но условие i < 10  
for (var i = 10; i < 10; i--) {
    // код
}

// Бесконечный цикл - i увеличивается на 2, но условие i <= 10
for (var i = 0; i <= 10; i += 2) {
    if (i === 6) break;
    // код
}
```

## Правильные примеры

```javascript
// Правильное направление - i увеличивается до 10
for (var i = 0; i < 10; i++) {
    // код
}

// Правильное направление - i уменьшается до 0
for (var i = 10; i > 0; i--) {
    // код
}

// Правильное направление - i увеличивается с шагом 2
for (var i = 0; i < 10; i += 2) {
    // код
}
```
