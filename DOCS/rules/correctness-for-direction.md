# for-direction

Проверяет направление цикла `for` для предотвращения бесконечных циклов. Правило обеспечивает, чтобы счетчик цикла двигался в правильном направлении по отношению к условию.

## Проблемные примеры

```javascript
for (var i = 0; i < 10; i--) {
  // бесконечный цикл
}

for (var i = 10; i >= 0; i++) {
  // бесконечный цикл
}

for (var i = 0; i > 10; i++) {
  // цикл никогда не выполнится
}
```

## Корректные примеры

```javascript
for (var i = 0; i < 10; i++) {
  // корректное направление
}

for (var i = 10; i >= 0; i--) {
  // корректное направление
}

for (var i = 0; i < 10; i += 2) {
  // корректное направление с шагом
}
```
