# nursery/named

Правило `named` из набора `nursery` контролирует аспект «Named». Оно помогает избегать проблем в коде, связанных с требованием «named», и поддерживать единый стиль проекта.

Подробные разъяснения и дополнительные рекомендации доступны в официальной документации Oxlint: https://oxc.rs/docs/guide/usage/linter/rules/named.

## ✅ Пример хорошего использования
Этот фрагмент демонстрирует ситуацию, в которой правило nursery/named выполняется.

```js
function examplePassingNursery() {
  // Требование «named» соблюдается.
  return true;
}
```

## ❌ Пример плохого использования
Здесь показана ситуация, при которой правило nursery/named сигнализирует о проблеме.

```js
function exampleFailingNursery() {
  // Требование «named» нарушено.
  return false;
}
```
